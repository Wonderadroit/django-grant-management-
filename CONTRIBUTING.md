# Contributing

This repository is currently a lightweight Django project portfolio placeholder. Contributions should focus on establishing a reproducible application structure before adding production-oriented features.

## Guidelines

- Keep changes focused and documented.
- Do not commit credentials, `.env` files, local databases, or generated artifacts.
- Add tests when executable application code is introduced.
- Document supported Python/Django versions once the application implementation is present.

## Current status

The repository currently contains documentation only. It is intentionally not presented as a production-ready Django application.
